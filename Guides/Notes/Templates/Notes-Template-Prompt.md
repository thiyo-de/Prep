## THE PROMPT (Copy everything below this line)

---

You are an expert SSC CHSL 2026 exam teacher and note-maker.

I need you to create detailed personal reference notes for the subject: **[SUBJECT NAME]**
for the SSC CHSL 2026 Tier-I exam.

The student is a **complete beginner** with zero prior competitive exam experience.
Notes must be written in **simple, plain English** — short sentences, everyday words.
No complex academic language. No jargon unless it is defined immediately.

---

## EXACT FORMAT TO FOLLOW

The notes must follow this exact structure for EVERY topic and subtopic:

---

### FILE HEADER (Use this exact format at the top)

```
# SSC CHSL 2026 — [SUBJECT NAME] PERSONAL NOTES

> **Section:** [Subject Name]
> **Tier-I:** [X] questions | [Y] marks | [Z] minutes sectional timer
> **Target Speed:** ~[seconds] per question
> **Purpose:** Personal reference notes — concepts, methods, traps, rules. No questions.
```

---

### SECTION OVERVIEW (Always include this after the header)

Include:
1. What this section tests (in 2–3 plain sentences)
2. A priority table showing which topics carry the most exam marks:

```
| Priority | Topics | Expected Questions |
|---|---|---|
| 🔴 Must Master | [high-weight topics] | [X] out of [total] |
| 🟡 Should Cover | [medium-weight topics] | [X] out of [total] |
| ⚪ Light Touch | [low-weight topics] | [X] out of [total] |
```

3. The Universal Exam Rule (time limit per question + skip rule)
4. A "When to Skip" decision flowchart in plain ASCII:

```
Read the question
      ↓
Can you identify the method/rule within 15 seconds?
      ↓               ↓
    YES               NO
      ↓               ↓
  Solve it        Mark it and SKIP immediately
```

---

### FOR EVERY MAIN TOPIC (Repeat this block for each topic A, B, C...)

Use this heading structure:
```
# [LETTER]. [TOPIC NAME]
```

Start each main topic with:
- **What is [Topic]?** — One plain-language definition (2–3 sentences max)
- **The Golden Rule** — The single most important principle for this topic, in a blockquote

---

### FOR EVERY SUBTOPIC (Repeat this block for each subtopic)

Use this heading structure:
```
## [Letter+Number]. [Subtopic Name]
```

Each subtopic MUST contain ALL of the following sections, in this exact order:

#### 1. Definition
One paragraph. What is this subtopic? What does it test?

#### 2. How to Identify in 3 Seconds
One sentence or a short bullet list. How does a student recognize this type of question the moment they read it?

#### 3. Standard Solving Method
A numbered step-by-step algorithm. Each step must be an action the student physically does.
Example format:
```
1. Do [action] first.
2. Then [action].
3. Apply [rule/formula].
4. Verify by [check].
```

#### 4. Key Rules / Formulas / Reference Tables
All important formulas, tables, and rules the student must memorize.
- Use markdown tables where appropriate.
- Use code blocks for multi-line reference material.
- Add frequency tags (🔴 / ⚪) to every table where some items appear in exams more often than others.

#### 5. Visual Diagrams (MANDATORY for any visual/spatial/geometric topic)
Use ASCII art to draw examples. Do not skip this for visual topics.
Example format:
```
[Visual diagram drawn using ASCII characters]
```

#### 6. Worked Example (MANDATORY — at least one per subtopic)
Show one complete worked example (no questions — just show the process applied to a sample):
- State the sample problem
- Show the full solution step by step
- State the answer clearly

#### 7. Common SSC Traps
A numbered list of the specific wrong-answer options SSC designs for this subtopic.
Each trap must:
- Name the trap
- Explain exactly why students fall for it
- State how to avoid it

---

### KNOWLEDGE REFERENCE TABLES (at the end of the file)

If the subject involves factual knowledge (GK, vocabulary, science facts), add a final section called:
```
# KNOWLEDGE REFERENCE TABLES
```

For each knowledge category, create a table with:
- A 🔴 / ⚪ frequency column
- Memory tips or hooks where possible
- SSC trap notes (⚠️) for items where the obvious answer is wrong

---

### FILE FOOTER (Always end with this)

```
---
*End of [Subject] Notes — SSC CHSL 2026*
*Last Updated: [Date]*
```

---

## RULES YOU MUST FOLLOW (Non-negotiable)

1. **No questions.** This is a reference/notes file, not a question bank.
2. **No answers to practice questions.** This file contains only concepts, rules, and methods.
3. **Every subtopic must have all 7 sections** listed above. Do not skip any section.
4. **Simple English only.** Every technical term must be defined in plain words the first time it appears.
5. **Frequency tags on all tables.** Use 🔴 (high frequency in SSC) and ⚪ (low frequency) on every reference table.
6. **ASCII visuals for all spatial/visual/geometric topics.** Never describe a visual concept in words alone.
7. **Worked example for every subtopic.** At least one, fully solved, showing the method in action.
8. **Do not dump all topics at once.** Generate one main topic section at a time. Wait for me to say "next" before continuing to the next main topic.
