## 1. What is an Analogy? | ஒப்புமை என்றால் என்ன?

An analogy compares **precise relationships**, not merely objects that belong to the same broad subject matter.

```
                         THE ANALOGY MECHANICAL ENGINE
                                       │
     [ Term A ] ──────────( Relationship R, Direction ──> )──────────> [ Term B ]
                                       ║
                           ( Must IDENTICALLY match )
                                       ║
                                       ▼
     [ Term C ] ──────────( Relationship R, Direction ──> )──────────> [ Term D ]
```

> [!NOTE]
> **Key Principle:** The colon (**:**) represents **“is related to”**, NOT a mathematical ratio or division. In a number analogy, an arithmetic or algebraic transformation governs the relation; in a word analogy, an empirical fact, biological function, or lexical definition governs it.

### Master Comparison Example:
*“Bird : Wing :: Fish : Fin”*
- **Relationship:** Animal $\to$ Essential anatomical organ for locomotion.
- **Direction:** Primary organism $\to$ Locomotor body part ($A \to B$).
- **Distractor Trap:** *“Fish : Water”* is an attractive association, but it switches the relationship from **Animal $\to$ Body Part** to **Animal $\to$ Habitat**.

> **தமிழில்:** முதல் ஜோடியில் உள்ள இரண்டு சொற்களுக்கிடையே என்ன உறவு உள்ளது என்பதை முதலில் சொல்ல வேண்டும். அதே உறவு, அதே வரிசையில் இரண்டாவது ஜோடியிலும் இருக்க வேண்டும். ஒரே தலைப்புடன் தொடர்பு இருப்பது (Association) மட்டும் போதாது; துல்லியமான உறவே (Exact Relationship) தேவை.

### 1.1 Essential Terminology Register

| Term | Tamil Meaning | Solving Function & Technical Meaning |
| :--- | :--- | :--- |
| **Analogy** | ஒப்புமை | Matching an identical underlying relationship across pairs or groups. |
| **Relationship** | தொடர்பு / உறவு | The exact functional, semantic, or mathematical connection between terms. |
| **Direction** | உறவின் வரிசை | The strict sequence of connection ($A \to B$ must correspond to $C \to D$, never $D \to C$). |
| **Attribute** | பண்பு | A measurable or observable feature such as shape, function, intensity, or magnitude. |
| **Category** | வகை | A formal taxonomic class (e.g., mammal, reptile, noble gas, prime number). |
| **Synonym** | ஒத்த பொருள் சொல் | A word sharing equivalent semantic meaning in the specified context. |
| **Antonym** | எதிர்ப்பொருள் சொல் | A word representing the exact semantic opposite. |
| **Intensity** | தீவிரத்தின் அளவு | Relative degree on an emotional or physical scale (e.g., *warm $\to$ hot*, *anger $\to$ rage*). |
| **Transformation** | மாற்ற விதி | The specific algebraic, numerical, or positional rule mapping the first term to the second. |
| **Consistent** | ஒரே விதமாகப் பொருந்தும் | The governing rule applies universally across all given examples without arbitrary shifts. |
| **Constraint** | கேள்வி விதிக்கும் கட்டுப்பாடு | An explicit restriction set by the question stem (e.g., *"do not split digits"*). |
| **Candidate Rule** | சாத்தியமான விதி | A hypothesized pattern that must be tested against all provided data points. |
| **Ambiguous** | பல பொருள் தரும் நிலை | Insufficient stem constraints where multiple equally valid rules survive. |
| **Counterexample** | விதி பொருந்தா எடுத்துக்காட்டு | A specific instance that invalidates a proposed hypothesis. |
| **Vector** | நோய்க்கிருமி கடத்தி | An organism (e.g., female *Anopheles* mosquito) that transmits a pathogen. |
| **Pathogen** | நோய்க்கிருமி | The microscopic causative biological agent of disease (e.g., *Plasmodium* parasite). |

## 2. Answer-Finding Priority: Which Rule Deserves Trust? | விடை தேடும் முன்னுரிமை

```
                         THE PRIORITY OF EVIDENCE FUNNEL
                                       │
     Level 1: EXPLICIT STEM CONSTRAINTS (e.g. "Do not split digits")
                         │
     Level 2: FITS EVERY GIVEN EXAMPLE (Zero counterexamples permitted)
                         │
     Level 3: EXACT RELATIONSHIP & DIRECTION SYMMETRY (A ──> B == C ──> D)
                         │
     Level 4: UNIFORM SCOPE & OPERATIONS (Consistent logic across pairs)
                         │
     Level 5: USES ALL RELEVANT TOKENS (Explains all digits/letters given)
                         │
     Level 6: ECONOMICAL & DIRECT REASONING (Direct rule over ad-hoc kludges)
                         │
     Level 7: OPTION COMPATIBILITY & DISTRACTOR ELIMINATION
                         │
     Level 8: DOCUMENT UNRESOLVED AMBIGUITY (If evidence under-specifies)
```

> [!IMPORTANT]
> **Core Exam Reality:**  
> **There is no universal mathematical law that multiplication beats addition, squares beat cubes, or a familiar GK association overrides an exact relationship.** Priority is determined strictly by the **strength of empirical evidence**, not by a superstitious hierarchy of arithmetic symbols!

---

### 2.1 The 8-Level Priority Architecture

| Level | Verification Criterion | Operational Action Required |
| :---: | :--- | :--- |
| **1** | **Explicit Instructions** | Obey all negative constraints (e.g., *“operations on whole numbers only; splitting into digits not permitted”*). |
| **2** | **Every Given Example** | If two or more reference pairs are given (e.g., $4 \to 16$ and $7 \to 49$), any rule failing even ONE example is disqualified immediately. |
| **3** | **Exact Relationship & Direction** | Enforce structural symmetry: Worker $\to$ Tool must not match Tool $\to$ Worker; Cause $\to$ Effect must not match Effect $\to$ Cause. |
| **4** | **Uniform Scope & Operators** | Do not square the first pair while cubing the second, or treat whole numbers in one pair and digits in another without explicit justification. |
| **5** | **Account for All Data Points** | A valid rule must explain every letter, numerical suffix, or visual marker present. Never ignore an inconvenient character. |
| **6** | **Economical, Repeatable Logic** | Prefer an elegant, direct transformation over complex multi-step ad-hoc formulas invented to fit a single target. |
| **7** | **Option Elimination & Verification** | Substitute the selected candidate into the final term and verify that all 3 distractor options fail the governing relationship. |
| **8** | **Documented Ambiguity** | When an under-specified question permits two equally sound rules producing different options, identify both and note the ambiguity. |

> **தமிழில்:** “முதல் ஜோடிக்கு ஒரு கணக்கு பொருந்துகிறது” என்பது மட்டும் போதாது. கேள்வியின் வரம்புகள், கொடுக்கப்பட்ட அனைத்து எடுத்துக்காட்டுகள் மற்றும் உறவின் சரியான வரிசை ஆகியவற்றிற்குப் பொருந்துகிறதா என்று பார்ப்பதே சரியான முறை.

### 2.3 What Official Answer Keys Do and Do Not Establish

- **Official Answer Key Authority:** Establishes the legally accepted option for scoring in that specific examination shift. It does not certify that the examiner's derivation was mathematically unique.
- **Publisher / Coach Explanations:** Represent proposed retrospective derivations. Never treat unofficial coaching shortcuts as binding grammar or mathematical laws.
- **Equivalent Mathematical Proofs:** If two methods yield the same correct option (e.g., $n(n+1)$ vs. $n^2 + n$), both are equally valid derivations.
- **Doubtful Questions Protocol:** When logging an ambiguous question in your notebook, record the exact stem, all 4 options, the specific shift/date, the official provisional vs. final key, and both competing derivations. Never rely on memorized fragments!

## 3. 💬 Word Analogy: The "Relationship Sentence" Engine

> [!TIP]
> **The Golden Rule of Word Analogy:**
> Never settle for a vague description like *"A is related to B"*. Always construct a **precise, testable sentence template**:
> - *"A is an instrument designed to measure B."*
> - *"A is the immature developmental stage of B."*
> - *"A is a specific classification instance of category B."*
> - *"A is the primary raw material processed into B."*

### 3.0 Master Taxonomy of Semantic Relationships

| Semantic Category | Standard Example | Sentence Testing Template | Critical Distractor Trap |
|---|---|---|---|
| **Worker → Tool** | Tailor : Needle | *A tailor uses a needle to perform work.* | Confusing the tool used with the product made or workplace. |
| **Worker → Workplace** | Teacher : School | *A teacher works inside a school.* | Not all workplaces are mutually exclusive; evaluate options strictly. |
| **Worker → Product** | Potter : Pot | *A potter crafts/creates a pot.* | A potter does *not* "work inside a pot" (role confusion). |
| **Tool → Function** | Scissors : Cutting | *Scissors are specifically designed for cutting.* | The material being cut (e.g. cloth) is not the mechanical function. |
| **Instrument → Quantity** | Thermometer : Temperature | *A thermometer measures physical temperature.* | Confusing the physical quantity with its unit of measurement. |
| **Quantity → Unit** | Force : Newton | *The standard SI unit of force is the newton.* | Instruments and units represent distinct ontological categories. |
| **Part → Whole** | Page : Book | *A page is an indivisible physical constituent of a book.* | A page is a *part* of a book, not a *type* of book. |
| **Type → Class** | Rose : Flower | *A rose is a specific taxonomic instance of a flower.* | A petal is a *part* of a flower, not a *type* of flower. |
| **Member → Collection** | Soldier : Army | *A soldier is an individual constituent member of an army.* | Member/collection differs fundamentally from creator/product. |
| **Material → Product** | Clay : Pot | *Clay is the primary raw material used to mold a pot.* | Multi-ingredient products must match baseline physical processing. |
| **Organ → Function** | Eye : Seeing | *The eye is the biological organ enabling vision.* | The external object perceived is a different relationship. |
| **Adult → Offspring** | Cat : Kitten | *A kitten is the immature offspring of a cat.* | Sexual dimorphism (male/female) is distinct from life-stage. |
| **Animal → Sound** | Dog : Bark | *A dog produces a bark.* | Animal vocalization differs from habitat or collective noun. |
| **Animal → Habitat** | Bee : Hive | *A bee colony constructs and inhabits a hive.* | Conventional shelter associations vs. universal biological habitat. |
| **Discipline → Subject** | Botany : Plants | *Botany is the scientific discipline studying plants.* | Specialist title (Botanist) vs. academic field (Botany). |
| **Cause → Effect** | Friction : Heat | *Mechanical friction directly generates thermal heat.* | Mere temporal correlation does not establish physical causation. |
| **Earlier → Later Stage** | Caterpillar : Butterfly | *A caterpillar undergoes metamorphosis to become a butterfly.* | Intermediate stages (pupa) need not be strictly adjacent if developmental. |
| **Synonym (Degree =)** | Begin : Start | *Begin and start share equivalent lexical denotations.* | Context, grammatical class, and part of speech must match. |
| **Antonym (Opposite)** | Expand : Contract | *Expand represents the exact opposite physical change of contract.* | Polysemy trap: "contract" can also mean a legal agreement. |
| **Intensity (Degree Δ)** | Warm : Hot | *Hot represents a significantly higher thermal intensity than warm.* | Intensity progression is not semantic opposition. |

A toe is the corresponding terminal digit of a **foot** (*பாதம்*).<br>3. *Distractor filter:* Leg is too broad; Nail is a sub-part of a toe; Shoe is an external protective garment. | **Selection:** **Foot**<br><br>✓ **Boundary Check:** Maintain immediate anatomical hierarchical proximity, not distant parent structures. |
| **T2**<br>`Taxonomy` | **Rose : Flower :: Mango : ?**<br><br>*(A) Fruit<br>(B) Seed<br>(C) Root<br>(D) Leaf* | 1. **Type → Class:** A rose is a specific botanical taxon belonging to the flower class.<br>2. A mango (culinary/botanical product) belongs to the **fruit** class.<br>3. *Distractor filter:* Seed, root, and leaf are plant organs/parts, not taxonomic categories. | **Selection:** **Fruit**<br><br>✓ **Boundary Check:** Clearly disambiguate noun senses (mango fruit vs. mango tree *Mangifera indica*). |
| **T3**<br>`Collective` | **Soldier : Army :: Player : ?**<br><br>*(A) Team<br>(B) Stadium<br>(C) Coach<br>(D) Ball* | 1. **Member → Organized Group:** A soldier is an active constituent member of an army.<br>2. A player is an active constituent member of a **team**.<br>3. *Distractor filter:* Stadium is the venue; Coach is the instructor; Ball is equipment. | **Selection:** **Team**<br><br>✓ **Boundary Check:** A collective group noun must not be confused with the group's physical arena or supervisor. |
| **T4**<br>`Processing` | **Clay : Pot :: Flour : ?**<br><br>*(A) Bread<br>(B) Baker<br>(C) Oven<br>(D) Field* | 1. **Raw Material → Manufactured Product:** Clay is molded and baked into a pot.<br>2. Flour (*மாவு*) is kneaded and baked into **bread**.<br>3. *Distractor filter:* Baker is the human agent; Oven is the thermal apparatus; Field is the agricultural origin. | **Selection:** **Bread**<br><br>✓ **Boundary Check:** Compares starting substance $\to$ finished product. Does not imply flour is the sole constituent. |
| **T5**<br>`Component` | Select the pair matching:<br>**Petal : Flower**<br><br>*(A) Rose : Flower<br>(B) Wheel : Bicycle<br>(C) Flower : Garden<br>(D) Seed : Seedling* | 1. **Constituent Part → Whole Assembly:** A petal (*இதழ்*) is an anatomical segment of a flower.<br>2. A wheel is an essential mechanical component of a bicycle.<br>3. *Distractor filter:* (A) Type $\to$ Class; (C) Item $\to$ Habitat/Location; (D) Developmental progression. | **Selection:** **Wheel : Bicycle**<br><br>✓ **Boundary Check:** Mere thematic association with flowers ("Rose : Flower") fails the structural part-to-whole test. |

<!-- separate learning boxes -->

> **தமிழில்:**
> - **T1:** கைக்கு விரல் போல, பாதத்திற்கு கால்விரல் (உறுப்பு → முழுப் பகுதி).
> - **T2:** ரோஜா மலர் வகையைச் சேர்ந்தது; மாம்பழம் கனி வகையைச் சேர்ந்தது (வகை → இனம்).
> - **T3:** படைவீரன் இராணுவத்தின் உறுப்பினர்; வீரர் அணியின் உறுப்பினர் (உறுப்பினர் → குழு).
> - **T4:** களிமண்ணிலிருந்து பானை செய்யப்படுவது போல, மாவிலிருந்து ரொட்டி செய்யப்படுகிறது (மூலப்பொருள் → தயாரிப்பு).
> - **T5:** பூவின் ஒரு பகுதி இதழ்; மிதிவண்டியின் ஒரு பகுதி சக்கரம் (பகுதி → முழுமை).

### 3.3 Five Worked Models: Meaning, Intensity, and Development

| Model ID | Exam Stem & Options | Candidate Analysis & Relational Proof | Official Key & Boundary Check |
|---|---|---|---|
| **S1**<br>`Synonym` | **Begin : Start :: End : ?**<br><br>*(A) Finish<br>(B) Open<br>(C) Delay<br>(D) Continue* | 1. **Semantic Equivalence (Synonyms):** Begin and start share identical verbal definitions.<br>2. End and **finish** share identical definitions in the verbal sense.<br>3. *Distractor filter:* Continue is antonymous; Open and delay represent unrelated action vectors. | **Selection:** **Finish**<br><br>✓ **Boundary Check:** Always confirm that grammatical part of speech (verb $\to$ verb) remains consistent. |
| **S2**<br>`Antonym` | **Expand : Contract :: Include : ?**<br><br>*(A) Exclude<br>(B) Contain<br>(C) Invite<br>(D) Combine* | 1. **Semantic Opposition (Antonyms):** Expand (*விரிவடை*) and contract (*சுருங்கு*) are polar opposites.<br>2. Include (*உள்ளடக்கு*) stands in direct opposition to **exclude** (*விலக்கு*).<br>3. *Distractor filter:* Contain is synonymous with inclusion; Invite and combine do not define polar opposites. | **Selection:** **Exclude**<br><br>✓ **Boundary Check:** Beware of polysemy: "contract" as a noun (legal document) vs. verb (shrink). |
| **S3**<br>`Intensity` | **Warm : Hot :: Cool : ?**<br><br>*(A) Cold<br>(B) Heat<br>(C) Mild<br>(D) Boiling* | 1. **Scalar Intensity Gradient (Low $\to$ High):** Hot represents increased thermal intensity relative to warm.<br>2. Moving further along the negative temperature gradient from cool yields **cold**.<br>3. *Distractor filter:* Heat is a noun/energy state; Mild is lower intensity; Boiling is extreme heat. | **Selection:** **Cold**<br><br>✓ **Boundary Check:** Warm and hot are not antonyms; do not switch to an opposition rule midway through. |
| **S4**<br>`Ontogeny` | **Caterpillar : Butterfly :: Tadpole : ?**<br><br>*(A) Frog<br>(B) Egg<br>(C) Fish<br>(D) Nest* | 1. **Larval Form → Adult Metamorphosis:** A caterpillar matures through pupation into an adult butterfly.<br>2. A tadpole (*தலைப்பிரட்டை*) undergoes metamorphosis into an adult **frog** (*தவளை*).<br>3. *Distractor filter:* Egg is an antecedent stage; Fish is a different vertebrate class; Nest is an avian habitat. | **Selection:** **Frog**<br><br>✓ **Boundary Check:** Rule is immature developmental phase $\to$ mature adult; immediate consecutive molts are not required. |
| **S5**<br>`Etiology` | **Malaria : Plasmodium :: Tuberculosis : ?**<br><br>*(A) Mycobacterium tuberculosis<br>(B) Anopheles mosquito<br>(C) Lung<br>(D) Vitamin C* | 1. **Disease → Causative Pathogen:** Malaria is caused by the protozoan parasite *Plasmodium*.<br>2. Tuberculosis is caused by the bacterial pathogen ***Mycobacterium tuberculosis***.<br>3. *Distractor filter:* Anopheles = insect vector; Lung = target organ; Vitamin C = organic nutrient. | **Selection:** **Mycobacterium tuberculosis**<br><br>✓ **Boundary Check:** Biological cause (pathogen), transmission carrier (vector), and target tissue are 3 strictly different relationships! |

<!-- separate learning boxes -->

> **தமிழில்:**
> - **S1:** தொடங்குதல் (Begin/Start) - முடித்தல் (End/Finish) நேரடி ஒத்த சொற்கள்.
> - **S2:** விரிவடைதல் x சுருங்குதல் போல, சேர்த்தல் x விலக்குதல் நேரடி எதிர்ச்சொற்கள்.
> - **S3:** வெதுவெதுப்பு அதிக வெப்பமாக மாறுவது போல, குளிர்ச்சி அதிகக் குளிராக (Cold) மாறுகிறது (தீவிரத்தின் அளவு).
> - **S4:** கம்பளிப்பூச்சி வண்ணத்துப்பூச்சியாக மாறுவது போல, தலைப்பிரட்டை தவளையாக மாறுகிறது (உருமாற்றம்/வளர்ச்சி).
> - **S5:** மலேரியாவை உண்டாக்குவது பிளாஸ்மோடியம் ஒட்டுண்ணி; காசநோயை (TB) உண்டாக்குவது மைக்கோபாக்டீரியம் டியூபர்குளோசிஸ் பாக்டீரியா. பெண் அனோபிலஸ் கொசு என்பது மலேரியாவைப் பரப்பும் கடத்தி (Vector) மட்டுமே!

## 4. ⚙️ Standard 7-Step Analogy Solving Protocol

Follow this deterministic execution pipeline on every single question to eliminate optical illusions and unforced reasoning errors:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 REUSABLE 7-STEP ANALOGY SOLVING PROTOCOL                    │
└─────────────────────────────────────────────────────────────────────────────┘
                                     │
   [1. READ] ──────────── Read stem carefully; detect explicit boundary limits
                                     │  (e.g. "Do NOT break into single digits")
                                     ▼
   [2. FORMULATE] ─────── Compose an unambiguous relationship sentence
                                     │  (e.g. "A is the SI unit of measurement for B")
                                     ▼
   [3. MAP DIRECTION] ─── Anchor source vector ($A \to B$ vs. $B \to A$)
                                     │  (Ensure answer pair mirrors identical order)
                                     ▼
   [4. PREDICT] ───────── Synthesize expected target BEFORE reading options
                                     │  (Prevents cognitive capture by deceptive distractors)
                                     ▼
   [5. FILTER OPTIONS] ── Test all 4 choices against the formulation sentence
                                     │  (Eliminate category errors, flipped vectors, partial rules)
                                     ▼
   [6. VERIFY ALL] ────── Test candidate rule across EVERY supplied pair/triple
                                     │  (A rule explaining pair 1 but failing pair 2 is dead!)
                                     ▼
   [7. DECIDE & LOG] ──── Commit best-supported option or log genuine ambiguity
```

### 5.4 🦠 Nutrition, Pathogens, Disease Vectors, and Physiology

| Relational Vector | Empirical Biological Fact | Critical Diagnostic Boundary & Limitations |
|---|---|---|
| **Deficiency → Disorder** | Vitamin A deficiency $\to$ **Night blindness** (*மாலைக்கண் நோய்*) | Night blindness may also stem from genetic retinopathy; nutritional deficiency is the primary exam association. |
| **Deficiency → Disorder** | Vitamin C deficiency $\to$ **Scurvy** (*ஸ்கர்வி*) | Scurvy is a collagen synthesis disorder caused by ascorbic acid deficit; not an infectious contagion. |

| **Disease → Vector** | Malaria $\to$ **Infected female *Anopheles* mosquito** | The mosquito is purely the biological transmission vector; male mosquitoes do not bite or transmit. |
| **Disease → Pathogen** | Tuberculosis $\to$ ***Mycobacterium tuberculosis* bacteria** | TB is bacterial; primary manifestation is pulmonary (lungs), but extrapulmonary TB can affect bones/brain. |

## 6. 🔢 Whole-Number Analogy: Mathematical Transformation Engine

### 6.1 Whole-Number vs. Digit Operations

> [!IMPORTANT]
> **Fundamental Mathematical Boundary:**
> - **Whole-Number Operation:** Treats $24$ as the atomic scalar integer *twenty-four* ($24 \times 3$, $24 + 5$, $24^2$).
> - **Digit Operation:** Deconstructs $24$ into independent positional numerals $2$ and $4$ ($2 + 4$, $2 \times 4$, $2^2 + 4^2$).
> 
> *Exam Constraint Notice:* Modern SSC, RRB, and State PSC question papers frequently state:
> > *"Operations should be performed on the whole numbers, without breaking down the numbers into its constituent digits (e.g. 13 — operations on 13 like adding/deleting/multiplying etc. can be done. Breaking down 13 into 1 and 3 is NOT allowed)."*
> 
> When this clause is present, digit-splitting methods are strictly illegal!

### 6.1.1 Core Mathematical Transformation Taxonomy

| Mathematical Operation | Algebraic Representation | Concrete Demonstration | Verification Checklist |
|---|---|---|---|
| **Constant Difference** | $x \to x \pm k$ | $8 \to 13$ and $12 \to 17$ ($+5$) | Offset $k$ must remain identically invariant across all given pairs. |
| **Scalar Multiplier** | $x \to x \times k \pm c$ | $6 \to 18$ and $9 \to 27$ ($\times 3$) | Scalar factor $k$ and constant $c$ must be fixed integers. |
| **Square / Cube Power** | $x \to x^2$ or $x \to x^3$ | $5 \to 25$ ($5^2$); $5 \to 125$ ($5^3$) | Look for proximity to known perfect square/cube benchmarks. |
| **Power with Offset** | $x \to x^2 \pm k$ or $x^3 \pm k$ | $3 \to 10$ ($3^2+1$); $4 \to 17$ ($4^2+1$) | Power exponent and linear adjustment must both remain constant. |
| **Consecutive Product** | $x \to x(x \pm 1)$ | $4 \to 20$ ($4 \times 5$); $6 \to 42$ ($6 \times 7$) | $n^2 + n$ and $n(n+1)$ are mathematically equivalent representations! |
| **Ordered Triple Vector** | $(a, b, c) \to c = f(a, b)$ | $(3, 4, 13) \to 3^2 + 4 = 13$ | Positional order of arguments $a$ and $b$ must be strictly preserved. |

## 7. 🧩 Digit-Based Analogy: Positional Arithmetic

> [!CAUTION]
> **Use ONLY When Explicitly Permitted or Mandated:**
> For a two-digit integer represented as $ab$, $a$ is the tens digit and $b$ is the units digit:
> $$\text{Integer Value} = 10a + b \quad (\text{Note: } ab \neq a \times b)$$
> 
> *Diagnostic Indicator:* When whole-number operations (differences, multiples, squares) produce massive discrepancies across given pairs, inspect digit transformations: **Digit Sum ($a+b$), Digit Product ($a \times b$), Sum of Squares ($a^2+b^2$), or Digit Reversal ($ba$).**

> **தமிழில்:**
> $62$ என்ற எண்ணின் இலக்கங்கள் $6, 2$.

> - இலக்கங்களின் பெருக்கல்: $6 \times 2 = 12$

> [!TIP]
> **The Opposite Letter Formula:**
> For any alphabet position $p$, its polar opposite letter in the alphabet sits at index:
> $$\text{Opposite Position} = 27 - p$$
> *Mnemonic Benchmark Pairs:* $\text{A} \leftrightarrow \text{Z}$, $\text{B} \leftrightarrow \text{Y}$ (*Boy*), $\text{C} \leftrightarrow \text{X}$ (*Crux*), $\text{D} \leftrightarrow \text{W}$ (*Dew*), $\text{E} \leftrightarrow \text{V}$ (*EV*), $\text{G} \leftrightarrow \text{T}$ (*GT Road*), $\text{H} \leftrightarrow \text{S}$ (*High School*), $\text{I} \leftrightarrow \text{R}$ (*Indian Railway*), $\text{J} \leftrightarrow \text{Q}$ (*Jungle Queen*), $\text{K} \leftrightarrow \text{P}$ (*Kurti/PK*), $\text{L} \leftrightarrow \text{O}$ (*Love*), $\text{M} \leftrightarrow \text{N}$ (*Man*).

> [!CAUTION]
> **Reversal of Order vs. Alphabet Opposites:**
> - Reversing the string $\text{CAT} \to \text{TAC}$ alters **positional sequence**, NOT letter identity.
> - Replacing letters with opposites $\text{CAT} \to \text{XZG}$ ($27-p$) alters **letter identity**, NOT sequence.
> - Applying both $\text{CAT} \to \text{GZX}$ alters **both sequence and identity**. Keep these operations strictly decoupled!

### 8.1.1 Letter Transformation Taxonomy

| Transformation Class | Analytical Verification Rule | Worked Demonstration |
|---|---|---|
| **Uniform Positional Shift** | Every single letter advances or recedes by an identical integer offset $+k$ or $-k$. | $\text{A}(+1) \to \text{B}$, $\text{C}(+1) \to \text{D}$ |
| **Position-Specific Shift** | Positional indices vary deterministically (e.g. 1st $+1$, 2nd $-1$, 3rd $+2$, 4th $-2$). | $\text{AZ} \to \text{BY}$ ($+1, -1$) |
| **Positional Permutation** | Letters undergo reordering without identity substitution (e.g. $[1, 2, 3] \to [3, 1, 2]$). | $\text{CAB} \to \text{BCA}$ |
| **Alphabet Opposites** | Each letter is replaced independently by its complementary counterpart ($27 - p$). | $\text{ABC} \to \text{ZYX}$ |
| **Multi-Stage Composite** | Positional permutation combined with shifts (apply in strict declared sequence). | Reverse then $+1$ |
| **Cyclic Wraparound** | $\text{Z} + 1 \to \text{A}$ occurs **only** when modular circularity is declared or proven. | $\text{YZ} \to \text{ZA}$ |

> **தமிழில்:**
> - எழுத்து மாறுகிறதா (Shift), எழுத்துகளின் இடம் மாறுகிறதா (Reordering/Permutation), அல்லது இரண்டும் மாறுகிறதா (Composite) என்று தனித்தனியாகப் பிரித்துச் சோதிக்கவும்.

## 9. 🔠 Alphanumeric Analogy: Compound Hybrid Codes

An alphanumeric code blends alphabetic tokens with numeric elements. In these models, always decouple:
1. **Independent Sub-Systems:** The letters follow an alphabet shift while the numbers follow an arithmetic progression ($+k, \times k$).
2. **Dependent Value Linkages:** The numbers are derived from letter positional values ($\sum p$, $p^2$, $p_1 - p_2$).

> **தமிழில்:**

## 10. 🔣 Symbol-String Analogy: Abstract Token Dynamics

In pure symbol analogies, glyphs (`@`, `#`, `*`, `!`) function as **discrete formal tokens**. Unless an explicit algebraic definition is provided (e.g. $a \star b = 2a + b$), treat them without arithmetic baggage. Track four spatial properties:
1. **Token Identity Preservation:** Do the tokens retain their original form?
2. **Positional Permutation:** How do character indices change ($123 \to 312$)?
3. **Multiplicity / Repetition:** Are tokens duplicated individually ($A \to AA$) or as a whole string?
4. **Deterministic Substitution:** Is token $X$ uniformly mapped to token $Y$?

<!-- separate learning boxes -->

> **தமிழில்:**
> கேள்வியில் குறியீட்டுக்கு புதிய விளக்கம் கொடுக்கப்படாத வரை, `*` என்பது பெருக்கல் அல்ல; அது ஒரு தனித்த அடையாளக் குறியீடு (Token) மட்டுமே.

## 11. 🧩 Figural Analogy (R20 Bridge): Visual Transformation Engine

> [!NOTE]
> **Foundation for Chapter R20:**
> These 5 text-grid benchmark models introduce visual and spatial transformation tracking without requiring external graphics.
> - `X` = Occupied / Filled cell
> - `.` = Empty cell
> 
> *Analytical Rule:* When analyzing spatial transformations, independently inspect:
> 1. **Orientation & Rotation** (Clockwise vs. Counter-Clockwise angle)
> 2. **Reflection & Mirror Line** (Vertical vs. Horizontal axis)
> 3. **Translation / Shift** (Row/Column linear offsets)
> 4. **Feature Inversion** (Outline $\leftrightarrow$ Solid Shading)

---

### 11.1 Five Worked Models: Geometric & Spatial Reasoning

#### V1 — Horizontal Reflection Across a Vertical Mirror Axis
**Stem:** Shape $A$ transforms into $B$ through left-to-right lateral inversion. Apply to $C$.

```text
      A               B               C             Answer
  ┌───────┐       ┌───────┐       ┌───────┐       ┌───────┐
  │ X . . │       │ . . X │       │ X X . │       │ . X X │
  │ X X . │  ──▶  │ . X X │       │ . X . │  ──▶  │ . X . │
  │ . . . │       │ . . . │       │ . . . │       │ . . . │
  └───────┘       └───────┘       └───────┘       └───────┘
```

1. **Transformation Rule:** Reverse cell sequence **within each horizontal row**; vertical row hierarchy remains fixed.
2. Row 1 of $C$ (`XX.`) laterally inverts to `.XX`.
3. Row 2 of $C$ (`.X.`) laterally inverts to `.X.` (symmetrical).
4. **Official Answer:** Grid with Row 1 `.XX`, Row 2 `.X.`, Row 3 `...`.
5. ✓ **Boundary Check:** Reversing rows vertically (top-to-bottom) would denote a *horizontal water-mirror line*, which is invalid here.

---

#### V2 — 90° Clockwise Rotation
**Stem:** Shape $A$ transforms into $B$ through a $90^\circ$ clockwise rotation. Apply to $C$.

```text
      A               B               C             Answer
  ┌───────┐       ┌───────┐       ┌───────┐       ┌───────┐
  │ X . . │       │ . X X │       │ . X . │       │ . . . │
  │ X . . │  ──▶  │ . . . │       │ . X . │  ──▶  │ X X X │
  │ . . . │       │ . . . │       │ . X . │       │ . . . │
  └───────┘       └───────┘       └───────┘       └───────┘
```

1. **Transformation Rule:** Coordinate transformation mapping $(r, c) \to (c, 4 - r)$ for a $3 \times 3$ matrix.
2. Vertical two-cell line in Col 1 rotates into a horizontal two-cell line in Row 1.
3. Shape $C$ consists of a vertical line of 3 cells down Column 2. Rotating $90^\circ$ clockwise maps it into a **horizontal line of 3 cells across Row 2**.
4. **Official Answer:** Grid with Row 1 `...`, Row 2 `XXX`, Row 3 `...`.
5. ✓ **Boundary Check:** Pure $180^\circ$ rotation or horizontal reflection would leave a vertical line vertical. Only $90^\circ$ turns vertical lines horizontal!

---

#### V3 — Pure Translation Without Spatial Reorientation
**Stem:** Move every occupied cell exactly one column to the right without wrapping. Apply to $C$.

```text
      A               B               C             Answer
  ┌───────┐       ┌───────┐       ┌───────┐       ┌───────┐
  │ X . . │       │ . X . │       │ . . . │       │ . . . │
  │ X . . │  ──▶  │ . X . │       │ X X . │  ──▶  │ . X X │
  │ . . . │       │ . . . │       │ . . . │       │ . . . │
  └───────┘       └───────┘       └───────┘       └───────┘
```

1. **Transformation Rule:** Coordinate translation $(r, c) \to (r, c+1)$ with zero angular rotation.
2. Shape $C$ occupies Row 2, Columns 1 and 2 (`XX.`).
3. Shifting 1 unit right translates occupied cells to Row 2, Columns 2 and 3 (`.XX`).
4. **Official Answer:** Grid with Row 1 `...`, Row 2 `.XX`, Row 3 `...`.
5. ✓ **Boundary Check:** Translation preserves angular orientation strictly; it never tilts or reflects the target object.

---

#### V4 — Shading Inversion With Structural Geometry Invariant
**Stem:** Outline elements become solid filled; solid filled elements become outlined. Spatial locations and counts remain invariant.
- **Source Pair:** $[\text{Outline Circle}, \text{Filled Square}] \longrightarrow [\text{Filled Circle}, \text{Outline Square}]$
- **Target Item:** $[\text{Filled Triangle}, \text{Outline Circle}] \longrightarrow \mathbf{?}$

1. **Element 1 (Triangle):** Filled $\to$ **Outline Triangle**.
2. **Element 2 (Circle):** Outline $\to$ **Filled Circle**.
3. **Official Answer:** $[\text{Outline Triangle}, \text{Filled Circle}]$.
4. ✓ **Boundary Check:** Swapping positional indices $(1 \leftrightarrow 2)$ violates spatial stability. Touch only the shading channel!

---

#### V5 — Resolving Transformation Ambiguity With Marker Signatures
**Stem:** Pair $A \to B$ displays a transformation that is either a **$90^\circ$ Clockwise Rotation** OR a **Vertical Mirror Reflection**. Apply the uniquely supported transformation to $C$. Note: Marker `O` is distinct from marker `X`.

```text
      A               B               C             Answer
  ┌───────┐       ┌───────┐       ┌───────┐       ┌───────┐
  │ X . . │       │ O . X │       │ . X . │       │ . . . │
  │ . . . │  ──▶  │ . . . │       │ . . . │  ──▶  │ O . X │
  │ O . . │       │ . . . │       │ . O . │       │ . . . │
  └───────┘       └───────┘       └───────┘       └───────┘
```

1. **Disambiguation Analysis:**
   - Tracking $X$ alone: Both $90^\circ$ CW rotation AND vertical reflection map Top-Left $(1, 1)$ to Top-Right $(1, 3)$. Ambiguity exists!
   - Tracking $O$ at Bottom-Left $(3, 1)$:
     - Under vertical mirror: $(3, 1)$ must map to Bottom-Right $(3, 3)$.
     - In observed output $B$, $O$ sits at **Top-Left $(1, 1)$**!
     - This precisely proves **$90^\circ$ Clockwise Rotation**: $(3, 1) \to (1, 4-3) = (1, 1)$.
2. **Apply Verified $90^\circ$ CW Rotation to $C$:**
   - $X$ at Top-Middle $(1, 2) \to (2, 4-1) = (2, 3)$ [Middle-Right].
   - $O$ at Bottom-Middle $(3, 2) \to (2, 4-3) = (2, 1)$ [Middle-Left].
3. **Official Answer:** Grid with Row 1 `...`, Row 2 `O.X`, Row 3 `...`.
4. ✓ **Boundary Check:** Multi-token visual markers permanently resolve apparent geometric degeneracies.

<!-- separate learning boxes -->

> **தமிழில்:**
> - **V1:** செங்குத்து ஆடிக் கோட்டில் இடது-வலது பிரதிபலிப்பு (Lateral Inversion).
> - **V2:** கடிகார திசையில் $90^\circ$ சுழற்சி (செங்குத்துக் கோடு கிடைமட்டக் கோடாக மாறும்).

> 4. **விதிமுறைகள் பின்பற்றப்பட்டதா?** — முழு எண் விதியா அல்லது இலக்க விதியா என்ற நிபந்தனை கவனிக்கப்பட்டதா?
