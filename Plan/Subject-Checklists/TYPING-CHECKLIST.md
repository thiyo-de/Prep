# Typing: Beginner-to-Exam-Practice Checklist

[Index and completion rules](README.md) | [Master plan](../FINAL-PLAN-NOV2026-MAY2027.md)

**Existing allocation:** 20 minutes during the workday lunch break, separate from English time. Keep time to eat. Start with 10 minutes finger/key accuracy + 10 minutes simple text. Later use a 15-minute passage + 5 minutes error review.

Typing is a practical skill: the 70% MCQ gate and chapter PYQ boxes do not apply. The stage numbers below are checklist labels, not book codes. Continue practice after ticking a stage.

## TF1 — Keyboard foundations

- [ ] Identify home-row keys and starting finger positions.
- [ ] Practise reaching keys with the intended fingers.
- [ ] Practise space, Shift, capitals and punctuation.
- [ ] Type slowly enough to identify and reduce repeated errors.
- [ ] Record an initial sample: duration, output, speed and accuracy.

## Stage 2 — Words and simple sentences

- [ ] Type common words accurately.
- [ ] Type short sentences with correct spaces and capitals.
- [ ] Practise numbers and punctuation appearing in passages.
- [ ] Identify recurring wrong keys/words and practise them.
- [ ] Repeat a comparable exercise and record whether errors decrease.

## Stage 3 — Continuous passages

- [ ] Copy a short unfamiliar passage without skipping lines.
- [ ] Maintain spacing and punctuation through longer passages.
- [ ] Keep a steady pace rather than rushing and repeatedly correcting.
- [ ] Record a repeatable baseline across three attempts.

## Stage 4 — Timed passages

- [ ] Complete a 15-minute practice passage.
- [ ] Record gross speed, accuracy, errors and net speed if the tool provides it.
- [ ] Keep the same scoring method when comparing results.
- [ ] Use the remaining 5 minutes to review recurring mistakes.
- [ ] Build toward the master plan's 35–40 English WPM practice target with high accuracy; this is not an official pass guarantee.

## Stage 5 — Exam-format data entry

- [ ] Check the applicable notice's duration, output measure and error rules.
- [ ] Practise with the permitted editing tools/settings.
- [ ] Complete a fresh passage under the relevant test conditions.
- [ ] Record output and errors using that exam's scoring method.
- [ ] Demonstrate the required standard consistently across three recorded attempts.

## Error follow-up and record

- [ ] Revisit recurring error patterns after 7 days on fresh text.
- [ ] Revisit them again after 21 days on fresh text.
- [ ] If three comparable attempts show no improvement, use the master plan's existing repair time.

The review boxes track a completed review cycle, not permanent mastery of typing. New errors start new review entries. Never memorise a passage and treat that speed as unseen-passage performance.
