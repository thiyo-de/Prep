## Tracker use and evidence

Open [`Tracker/tracker.html`](Tracker/tracker.html) in Chrome or Edge and connect this README before editing. Connecting imports existing records. Saves update edited topic rows and the two derived checklist/accuracy metrics; mock records, notes elsewhere, and other sections are preserved. Reconnect if the file changes externally. Unconnected edits are disabled. Keep a backup of this file.

Score = 2 × correct − 0.5 × wrong. For example, 88 correct and 12 wrong = 170/200. Fraction scores contribute to recorded drill accuracy; the existing Analogy score `90` is retained but excluded until its denominator is known. Completion is self-reported, not proof of mastery.
